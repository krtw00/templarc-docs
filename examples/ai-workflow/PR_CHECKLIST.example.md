# PR_CHECKLIST Example

## 変更概要

- 何を変えたか: 問い合わせ一覧へ担当者フィルタを追加した
- なぜ変えたか: 担当者別の滞留状況をすぐ確認できるようにするため
- どのタスクに対応するか: `TASK_BRIEF-inquiry-assignee-filter.md`

## 確認項目

- [x] 受け入れ条件を満たす
- [x] 差分の責務が一貫している
- [x] 関連ドキュメントを更新した
- [x] テストまたは手動確認を実施した
- [x] 既知のリスクを説明した
- [x] 破壊的変更の有無を明示した

## 検証結果

- 実行したコマンド: `pnpm test --filter inquiries`, `bundle exec rspec spec/requests/inquiries_spec.rb`
- 手動確認: 担当者未指定、担当者指定、権限不足ユーザーの表示を確認
- 未実施項目と理由: E2E は nightly ジョブで別実施

## 影響範囲

- 影響する利用者: サポート担当、運用責任者
- 影響する機能: 問い合わせ一覧
- ロールバック方法: フィルタ UI と API 条件を feature flag で停止する

## レビュワー向け観点

- 権限制御を崩していないか
- フィルタ未指定時の既存挙動を維持しているか
- クエリ性能への影響説明が妥当か
