# PR_CHECKLIST

## 使い方

- PR作成前に記入する
- レビュワーが判断しやすい状態にしてから提出する
- 該当しない項目は `N/A` と明記する

- どのタスクに対応するか:

## 確認項目

- [ ] 受け入れ条件を満たす
- [ ] 差分の責務が一貫している
- [ ] 関連ドキュメントを更新した
- [ ] テストまたは手動確認を実施した
- [ ] 既知のリスクを説明した
- [ ] 破壊的変更の有無を明示した

## レビュワー向け観点

- 仕様の解釈に無理がないか
- 変更範囲がタスクに対して広すぎないか
- 検証内容が十分か
- 運用上の副作用が見落とされていないか
