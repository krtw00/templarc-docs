# AGENTS

## この文書の役割

`AGENTS.md` は、AI に毎回守らせる共通ルールをまとめる。
タスク固有の内容は `TASK_BRIEF.md` に書く。

## 優先順位

1. `TASK_BRIEF.md`
2. `PROJECT_BRIEF.md`
3. `templarc-core` 由来の設計ドキュメント
4. 実装コードとテスト

## 開始前チェック

- 目的と受け入れ条件を確認する
- 変更対象ファイルを確認する
- 触らない領域を確認する
- 必要な検証コマンドを確認する

## 基本ルール

- 要件が曖昧な場合は、変更前に前提を短く明示する
- 仕様変更を伴う場合は、コードより先に関連文書を更新する
- 既存変更を無断で巻き戻さない
- 変更後は必ず検証結果を残す
- 不要な横断変更を避ける

## コード変更ルール

- 1タスク1責務を守る
- 既存の命名、構造、テストスタイルに合わせる
- 一時対応と恒久対応を混ぜない
- 破壊的変更は明示する

## ドキュメント更新ルール

- 仕様が変わるなら、対応する文書も同時に更新する
- 実装メモや一時メモは永続ドキュメントに残さない
- 参照先が増えたら最小限の説明を添える

## 出力ルール

- 何を変えるかを先に短く述べる
- 実行した検証を明記する
- 未解決事項があれば最後に残す

## 仕上げチェック

- 受け入れ条件を満たしているか
- 関連文書が同期されているか
- テストや手動確認の結果を残したか
- リスクを説明できるか

## 依頼テンプレート

```markdown
目的:
背景:
対象:
制約:
受け入れ条件:
検証:
```
