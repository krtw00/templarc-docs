# AGENTS

## 優先順位

1. `TASK_BRIEF.md`
2. `PROJECT_BRIEF.md`
3. `templarc-core` 由来の設計ドキュメント
4. 実装コードとテスト

## 基本ルール

- 要件が曖昧な場合は、変更前に前提を短く明示する
- 仕様変更を伴う場合は、コードより先に関連文書を更新する
- 既存変更を無断で巻き戻さない
- 変更後は必ず検証結果を残す

## 出力ルール

- 何を変えるかを先に短く述べる
- 実行した検証を明記する
- 未解決事項があれば最後に残す

## 依頼テンプレート

```markdown
目的:
対象:
制約:
受け入れ条件:
検証:
```
